# Task v1.0-05: Declare and freeze the public API surface

## Context

Read `CLAUDE.md` fully — specifically the Architectural-constraints clause:
*"Public API stability: anything documented in README is considered public.
Breaking changes require a major version bump and a CHANGELOG entry. Internal
modules (anything starting with `_`) can change freely."* Read `README.md`,
`docs/OBJECT-LISTS.md`, and every module's top-level exports. Confirm v1.0-02,
v1.0-03, v1.0-04 have merged.

## Why this task exists

At 1.0 the stability promise stops being aspirational and starts being a
contract. Right now "the public API" is defined only implicitly by "what the
README happens to mention". Before freezing, the surface must be made
**explicit and intentional**: exactly what is public, exactly what is internal,
enforced by `__all__` and documented in one place. Otherwise the first
accidental rename after 1.0 silently breaks the contract.

## Design decisions (already made)

- **`__all__` on every public module.** `mayaastrolib/__init__.py`,
  `chart.py`, `object.py`, `aspects.py`, `datetime.py`, `geopos.py`, `const.py`,
  and the `vedic/` public modules each declare `__all__` listing only their
  intended public names. Anything not in `__all__` is internal-by-convention.
- **Top-level convenience re-exports.** `mayaastrolib/__init__.py` should
  re-export the everyday entry points so `from mayaastrolib import Chart,
  Datetime, GeoPos, const` works (the README already implies this). Decide the
  canonical set and list it in `__all__`.
- **`docs/API-STABILITY.md` is the single source of truth.** It lists: the
  frozen public surface (module → public names), the stability tier of the
  `vedic` subsystem (propose: **public but versioned per-module**, since some
  pieces are explicitly "simplified/heuristic"), and the rule for what
  `_`-prefix vs `__all__`-exclusion means.
- **No renames of public names in this task.** If something public is
  badly named, note it in `docs/IDEAS.md` for a *pre-1.0* rename decision —
  don't sneak it in here.

## Task scope

1. Add `__all__` to every public module (audit each name: is it genuinely part
   of the contract, or an implementation detail that leaked?).
2. Curate `mayaastrolib/__init__.py` convenience re-exports + its `__all__`.
3. Write `docs/API-STABILITY.md`: the frozen surface, the vedic tiering, the
   internal-module rule, and the "how we make breaking changes after 1.0"
   policy (major bump + CHANGELOG "Removed (BREAKING)" + one minor-version
   deprecation window).
4. Reconcile README ↔ reality: every symbol the README shows must be public and
   importable exactly as shown; anything public the README omits either gets a
   mention or a note in API-STABILITY.md that it's public-but-undocumented.

## Tests

- New `tests/test_public_api.py`:
  - Importing each public symbol named in `docs/API-STABILITY.md` succeeds.
  - Every name in each module's `__all__` actually exists on the module
    (`for n in mod.__all__: assert hasattr(mod, n)`).
  - The README quick-start snippet runs end-to-end (extract it or replicate it)
    and produces a `Sun` object — this pins the documented entry points.
- Full existing suite still passes.

## Out of scope

- Renaming or removing any public symbol (only *declaring* the surface).
- Sphinx/generated docs (task v1.0-06 consumes this task's `__all__`).
- Changing the vedic module behaviour.

## Process

Branch `v1.0-05-freeze-public-api`. Commits:
`feat: declare __all__ across public modules`,
`feat: curate top-level convenience re-exports`,
`docs: add API-STABILITY.md and reconcile README`,
`test: add public-API surface tests`, then the `docs:` checklist commit. Full
pre-completion checklist. Push, verify CI, DO NOT merge.

## Definition of done

- Every public module has an intentional `__all__`; `tests/test_public_api.py`
  enforces it.
- `docs/API-STABILITY.md` exists and defines the frozen surface + post-1.0
  breaking-change policy.
- README symbols all resolve; the quick-start runs in a test.
- Checklist passes; CI green.
