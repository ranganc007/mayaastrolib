## Why this task exists

Three vedic capabilities currently ship a documented *stand-in* rather than the
classical computation. They are honest about it, but "complete Vedic subsystem"
reads better at 1.0 if the headline ones are real.

## 7a — Full six-fold Shadbala

Currently yoga strength uses an accidental-dignity-weighted approximation, not
the classical Shadbala. Implement the full six *balas* per BPHS Ch. 27:

- **Sthana Bala** (positional: Uchcha, Sapta-vargaja, Ojha-Yugma, Kendradi,
  Drekkana).
- **Dig Bala** (directional strength).
- **Kala Bala** (temporal: Nathonnatha, Paksha, Tribhaga, Abda/Masa/Vara/Hora
  lords, Ayana, Yuddha).
- **Cheshta Bala** (motional — needs real planet speed; raise on symbolic
  charts, as `tajika_aspects` already does).
- **Naisargika Bala** (natural, fixed per graha).
- **Drik Bala** (aspectual).

Output `ShadbalaResult` with per-component Rupas and the total, plus the
Ishta/Kashta phala if cheap. Rewire `vedic.yogas.yoga_strength_weighted` to
optionally consume real Shadbala (keep the existing lightweight scorer as a
documented fast path). Reference values: pin at least one chart against a
published Shadbala table (e.g. a worked BPHS example) at a stated tolerance.

## 7b — The Saham / Tajika-yoga long tail

- Extend `tajika._SAHAM_FORMULAS` from the current 14 to the full classical
  ~50 Sahams (Raman, *Varshaphala*). Keep the data-driven table format.
- Add the remaining ~13 Tajika yogas beyond Ithasala/Isharafa/Nakta
  (Kamboola, Gairi-Kamboola, Khallasara, Radda, Duruph, Dutthotha-daivutha,
  Tambira, Kuttha, Durapha, Manau, etc.), each with its classical condition.
  Note source variance in docstrings where authorities disagree.

## 7c — Full KP horary chart with house cusps

`vedic/kp.py` has the Lagna sub-lord chain but not a full horary chart. Add
Placidus (or the KP-standard) **house cusps** to `kp_horary(n)`, each resolved
to its sub-lord chain, so the result is a complete KP horary chart
(12 cusp sub-lords + planet sub-lords), not just the Lagna.

## Tests

- 7a: component-wise unit tests (each bala in a known range) + one full-chart
  reference pinned against a published table.
- 7b: each new Saham hand-checked from a fixed chart; each new yoga has a
  positive and a negative fixture.
- 7c: 12 cusps present, ordered, each with a valid sub-lord chain; a known
  horary number reproduces a published KP cusp table within tolerance.
